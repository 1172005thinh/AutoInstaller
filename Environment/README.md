# ENVIRONMENT

This directory includes all the environment installers.

Currently, support:
- **All in One C++ Runtimes**
- **Java Runtime Environment (JRE)**
- **Python**
- **IDE**

## ALL IN ONE C++ RUNTIMES

This is an offline all in one c++ runtimes installer. It installs a fresh `all in one c++ runtimes` with `default configuration`.

Shout out to [abbodi1406](https://github.com/abbodi1406) for a universall All-in-One installer.

## JRE

This is an offline `JRE` installer. It installs a fresh `JRE` with `default configuration`. `Oracle` should be used.

## PYTHON

This is an offline `python` installer. It installs a fresh `python` with `default configuration`.

## IDE

This is an offline `IDE` installer. It installs:

- **VisualStudio** - Launcher only

You must run the launcher to manually install your own packages.
