# TOOLS

This directory includes all the tools installers.

Currently, support:
- **ARCHIVERS**: 7z, WinRAR
- **DESKTOPSUPPORTERS**: TeamViewer, UltraViewer
- **EDITORS**: VSCode, Notepad++
- **SCREENRECORDERS**: OBS

## ARCHIVERS

This directory includes:

- **7z**: An archive utility that supports the 7z file format, as well as many other archive file formats.
- **WinRAR**: A shareware file archiver and compression utility. It can create and open .rar files and also handles common archive formats like .zip, .tar, .iso, and more. A license key `rarreg.key` is required for activation.

## DESKTOPSUPPORTERS

This directory includes:

- **TeamViewer**: A proprietary cross-platform commercial software for remote computer access, remote control, online meetings, web conferencing and file transfer between computers.
- **UltraViewer**: A free remote access software that allows you to remote control another computer.

## EDITORS

This directory includes:

- **Visual Studio Code**: A free source-code editor made by Microsoft. It is widely used by developers for its features and extensions.
- **Notepad++**: A free source code editor and Notepad replacement that supports several languages. It is lightweight and easy to use.

## SCREENRECORDERS

This directory includes:

- **OBS Studio**: A free and open-source software for video recording and live streaming.
