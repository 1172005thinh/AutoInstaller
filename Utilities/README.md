# UTILITIES

This directory includes all the utilities installers.

Currently, support:
- **FILEEXPLORER**: Custom shell menu from `NileSoft Shell`
- **MEDIAPLAYERS**: K-Lite Codec MPC
- **VIETNAMESEKEYBOARDS**: Unikey by `Phạm Kim Long`
- **FONTS**: A fonts collection directory, please download them via [HungThinhCloud Shared Fonts](https://drive.hungthinhcloud.freeddns.org/share/yZzCuQ9e/Fonts/).

## FILEEXPLORER

This is an offline `NileSoft Shell` installer. It installs a fresh `NileSoft Shell` with `default configuration`.

## MEDIAPLAYERS

This is an offline `K-Lite Codec MPC` installer. It installs a fresh `K-Lite Codec MPC` with `default configuration`.

## VIETNAMESEKEYBOARDS

This is an offline `Unikey` installer. It installs a fresh `Unikey` with `default configuration`.
